# E-Cab Booking Website

This is an e-cab booking website built with [Next.js](https://nextjs.org), providing users with a seamless and efficient way to book cabs online.

## Features

- User authentication (signup, login, logout, verify)
- User profile management
- Real-time cab booking and tracking
- Interactive map integration for pickup and drop locations
- Payment processing
- Responsive design for desktop and mobile
- Email notifications for booking confirmations

## Usage

- Sign up or log in to your account.
- Use the map to select pickup and drop locations.
- Book a cab and proceed to payment.
- View your booking history and profile details.

## API Routes

The project includes several API routes for user management and booking:

- `POST /api/user/signup` - User registration
- `POST /api/user/login` - User login
- `POST /api/user/logout` - User logout
- `GET /api/user/me` - Get current user profile
- `POST /api/user/verify` - Verify user email or phone
